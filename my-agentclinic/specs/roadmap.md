# Roadmap

## Phase 1: Foundations
- **Status: Complete**
- Initialize the TypeScript project and confirm the build tooling works.
- Set up the project structure and basic configuration.
- Add SQLite and define the initial schema for agents, ailments, therapies, and appointments.
- Create the informational home page with a shared layout composed of separate header, main, and footer components.

## Phase 2: Core app shell
- Create the server-side app skeleton.
- Add basic routes for the dashboard and patient/agent overview.
- Render the initial pages in a modern browser-friendly layout.

## Phase 3: Agent care features
- Implement ailment tracking and therapy management.
- Add appointment booking flows and scheduling logic.
- Show data in a simple, accessible dashboard.

## Phase 4: UX polish
- Improve visuals and responsiveness.
- Add validation and better feedback for booking and form interactions.
- Make the interface attractive and easy to demo.

## Phase 5: Reliability and demo readiness
- Validate the app against the mission and stakeholder goals.
- Test the flows for scheduling, therapy management, and dashboard access.
- Prepare the project for demos and educational use.
